# RESTful-APIs---quora

A basic web application to create, view, edit, and delete posts. This project is a simple implementation of RESTful APIs for learning purposes.

## Features

- **View Posts**: See a list of all posts.  
- **Create Post**: Add a new post with a username and content.  
- **Edit Post**: Update the content of a post.  
- **Delete Post**: Remove unwanted posts.  

## Technologies Used

- **Node.js** and **Express.js** for the backend.  
- **EJS** for dynamic views.  
- **Bootstrap** for styling.  
- **UUID** for unique post IDs.  
- **Method-Override** to enable PATCH and DELETE methods.

## How to Run

1. Clone this repository:  
   ```bash
   git clone <repository_url>

2. Install dependencies:
   ```bash
   npm install

3. Start the server:
   ```bash
   node index.js

4. Open in your browser:  
   [http://localhost:8080/posts](http://localhost:8080/posts)
